WICHTIG: KONTAKTFORMULAR EINMAL AKTIVIEREN
Das Formular verwendet FormSubmit, damit es auch auf einer statischen Website direkt an
info@obc.co.at senden kann.

Nach dem Hochladen:
1. www.obc.co.at öffnen.
2. Eine TEST-Anfrage über das Kontaktformular absenden.
3. FormSubmit sendet eine Aktivierungs-E-Mail an info@obc.co.at.
4. Den Bestätigungs-/Aktivierungslink in dieser E-Mail anklicken.
5. Danach nochmals eine TEST-Anfrage absenden.
6. Prüfen, ob die Anfrage ankommt und anschließend danke.html angezeigt wird.

Hinweis Datenschutz Formular:
FormSubmit ist ein externer Formulardienst und verarbeitet die beim Absenden eingegebenen Daten.
Die Datenschutzerklärung wurde darauf angepasst. Für eine dauerhaft maximal datenschutzorientierte
Lösung kann später auf einen EU-gehosteten Form-Endpoint mit AVV oder einen eigenen Server-Endpunkt
umgestellt werden; dafür muss in index.html lediglich das action-Ziel des Formulars geändert und die
Datenschutzerklärung entsprechend angepasst werden.
